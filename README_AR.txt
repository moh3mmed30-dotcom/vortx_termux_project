VORTX AI Toolbox — نسخة Termux

المحتويات:
- app.py: خادم Flask وواجهة API.
- templates/index.html: واجهة عربية/إنجليزية، زر رجوع للقائمة الرئيسية، مظهر نهاري/ليلي، وروابط المطور.
- requirements.txt: المكتبات المطلوبة.

التشغيل على Termux:
1) افتح Termux وانتقل إلى مجلد المشروع:
   cd /storage/emulated/0/vortx_termux_project
2) ثبّت المكتبات:
   pip install -r requirements.txt
3) شغّل الخادم:
   python app.py
4) افتح المتصفح على:
   http://127.0.0.1:8080

لو واجهت مشكلة صلاحيات الوصول للتخزين، نفّذ termux-setup-storage ثم أعد فتح Termux.
